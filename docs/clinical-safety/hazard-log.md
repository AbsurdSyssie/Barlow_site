# Hazard log (starter)

This is a starter hazard log for the Open GP Practice Website template. It records the hazards the template is designed to control and how. The risk ratings below had an initial review by Marcus Baw in October 2026.

A practice publishing a site made with this template is responsible for the accuracy of its own content. Practices and ICBs carrying out a DCB0160 assessment can use this log as a starting point.

Ratings use the DCB0129 risk matrix: severity (1 minor to 5 catastrophic) and likelihood (1 very low to 5 very high).

## Open actions

### Unofficial recovery demo controls (H1, H2, H3, H5, H7, H10)

This copy is a personal archive-recovery demonstration, not a practice deployment. No practice sign-off has occurred. `build:demo` uses a separate config and clears `_preview` before rendering; production `_site` is not read or written. Only absent `site.content_last_reviewed` and `gp_earnings.financial_year` may be deferred. Invalid supplied values, missing other required facts, placeholders and untrusted embeds still block. The default checker and production build remain strict. Undated earnings are omitted, not relabelled with an invented year.

Every preview HTML page, including errors and recovered Markdown pages, uses the base layout with one clear unofficial banner, noindex/nofollow, no sign-off claim and the unchanged urgent-help partial. Preview-only overrides are restricted to a fixed list of informational pages, never urgent-help or about/earnings. Recovered content must not contain patient forms, trackers, embeds or clinical advice. Source-derived ordinary practice information is written as patient journeys; capture dates, conflicts and unresolved approvals stay in the administrative inventory and queries, not repeated on patient pages. Generic template service promises are replaced in the demo where the source contradicts them. Unknown-year earnings are entirely omitted. Tests in `tests/preview.test.js` exercise these boundaries with fictional data.

### External PATCHS links enabled, 30 October 2026 (H2, H5, H7, H10)

The user explicitly authorised source-based practice content and live outgoing supplier links in this unofficial demo, not an official launch. The exact source href `https://patchs.ai/practice/barlowmedicalcentre` was copied from the archived appointments button and independently checked by read-only browser navigation: the live page identifies Barlow Medical Centre. The NHS P84034 profile corroborates name, address and reception phone. Evidence is recorded in `practice/sources/online-consultation.json` and the migration inventory. No account, patient information, form submission or cookie-consent interaction was used. The external service's current notice distinguishes clinical requests (7am to 10am weekdays) from Admin Query requests (10am to 6:30pm). That distinction and the urgent-after-10am phone route are preserved; no online availability or response-time guarantee is made. The appointments page retains emergency signposting above the action. The homepage action now uses the configured consultation URL, not a disabled or generic destination; contact routes through appointments, and prescriptions/results/fit notes link to the same evidenced supplier landing page. No archive form, guessed deep link or embed is used.

`npm run audit:demo` checks every rendered demo page for exactly one banner, noindex, urgent help, local link integrity, no forms/frames/external scripts, no leaked archive/audit prose, no invented review date or earnings year, and checks source-equal supplier anchors and the practice-specific appointment/prescription distinctions. Template tests use fictional data. Production validation has not been relaxed. Residual risk: the live supplier may close requests or change availability; the landing page, not this static site, controls whether requests are accepted. Independent risk review of this operational-link change remains outstanding; no practice sign-off or revised risk rating is claimed.

Residual risks: public noindex is advisory, not access control; search engines may ignore it, and users may still mistake archived content for current care instructions. Staff names and source content require current practice consent and rights review before an official launch. Owner for sign-off remains the practice's responsible safety lead, not this demonstration's maintainer. Status: unapproved demo, independent review outstanding. No revised residual risk rating is claimed.
